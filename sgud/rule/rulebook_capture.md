- **CAP-04 失敗分流與 dead(唯一規則來源 `src/stores/fetchPolicy.mjs classifyFetch`)**:
  - final(HTTP 400／402／404／405／406／410／414／451〔`FINAL_HTTP_CODES`〕、其他非 401／403／407 之 4xx、invalid-*、paywall、not-found、soft-404、adapter 收攤〔非暫時性者〕、**pdf**〔選抓取器前依網址判:路徑 `.pdf` 結尾或 arXiv `/pdf/`,不發請求、不佔瀏覽器名額;`isPdfUrl`〕、瀏覽器亦判標題與正文不符之 title-mismatch〔CS2;正文抓取器判不符者先轉瀏覽器重抓〕)→ **一輪即 dead**(feed 可用〔長度＋閘〕者仍走 feed 退路)。
  - retry(407／408／425／429／5xx、**adapter 之暫時性失敗**〔5xx／429／逾時／連線／抓取函數拋錯 → `adapter-transient`;內建 adapter 中 fallback:false 者,其 API 暫時性失敗原樣帶 adapterId 收攤,不可一輪即判 dead〕、自訂抓取器之失敗、未知 reason)→ `fetchTries＋1` 退回 new、**退避** `retryAt`(`capture.articles.retryBackoffHours`×4^(n-1):6 時、24 時…;退避中不取件、不丟),試滿 `capture.articles.maxTries` 才 dead。
